# Scaffold Basics

A small Flutter project for practicing the fundamentals of building a Material app and working with basic widget structure.

## Tech stack
- Flutter
- Dart
- Material Design

## Project structure
- `lib/main.dart` starts the application.
- `lib/` contains the Flutter UI code.
- `android/` and `ios/` contain the platform projects.
- `test/` contains automated tests.

## Getting started
1. Install Flutter and confirm your environment with `flutter doctor`.
2. Clone this repository.
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```

## Purpose
This repository is intended as a simple learning project for understanding Flutter scaffolding, app entry points, and basic UI composition.
